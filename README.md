# Week-11-Lab-Aura-Georgia-
This repository intends to describe the two functions utilized throughout 
Problem 5 of the Week 11 Lab. The Function 1 script involves a function that 
estimates the request rates of bikes within certain origin and destination pairs
across a specific time window by transforming trip data into estimated rates.

Function 2 simulates estimated arrival rates by randomly generating arrival 
rates based on Poisson distribution that is 
dependent on the hourly demand rates previously calculated.
